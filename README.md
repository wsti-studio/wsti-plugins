# WSTI plugins

Claude Code plugins for the WSTI team. Members only: the board signs you in with your WSTI Google account.

Install the WSTI board:

```
claude plugin marketplace add wsti-studio/wsti-plugins
claude plugin install wsti-ai-os@wsti
claude mcp login plugin:wsti-ai-os:board
```

The plugin's source of truth is `plugin/` in the private `wsti-studio/ai-os` repository; this repository is a published copy.
